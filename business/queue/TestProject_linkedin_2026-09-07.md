Just shipped a quick side project called **TestProject**! 🚀

It’s a super minimal Next.js app built around a clean `/hello` route—basically a lightweight, no-nonsense starter to test out some fresh ideas. 

**The Stack:**
• Next.js
• Tailwind CSS
• TypeScript

**The Challenge:**
One fun little hurdle was getting TypeScript to play nice with the Next.js App Router route handlers for the `/hello` endpoint. I wanted strict typing on the JSON response without adding a bunch of messy boilerplate. Solved it by creating a simple generic wrapper for the response objects, keeping the code clean and fully type-safe.

It always feels good to turn a blank folder into a working project, even a tiny one!
